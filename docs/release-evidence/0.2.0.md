Use nested ordinary files, including a binary file and a Unicode filename, alongside the ISO. Record the selected label, allocation size, and reserved space.

- [ ] Install the signed candidate and confirm its package, version, and APK hash match the identity table. If upgrading an existing signed 0.1.2 installation, install over it without uninstalling and confirm app launch and USB detection.
- [ ] Install MBR with the expected settings. Copy the ISO and ordinary files. Save their SHA-256 hashes.
- [ ] Reconnect the USB and confirm the app detects MBR and the installed Ventoy version.
- [ ] Run MBR repair, reconnect, and compare the ordinary file hashes. Record the detected version.
- [ ] Boot the ISO from MBR on the available computer, if possible. Record the computer, firmware mode, ISO hash, and observed result.
- [ ] Install GPT with the signed candidate. Confirm the stable package, GPT style, and expected settings. Copy the same ISO and ordinary files and save hashes.

# Vendroid 0.2.0

Vendroid 0.2.0 adds GPT installation alongside MBR. It can install, detect, validate, update, and repair Ventoy GPT layouts, and it keeps ordinary files in place during update and repair.

MBR remains the recommended default. Drives above 2 TiB stay in the Vendroid beta until real large-drive evidence is available.

This release also syncs the drive before reporting success, checks a Ventoy payload before writing it, gives each formatted volume its own serial number, and fixes a hang while formatting certain drive sizes. Vendroid no longer offers to open ISO or IMG files directly, because that overwrote the whole drive.

Installing Ventoy erases the selected drive, so back it up first. Keep the drive connected until the operation finishes.

Testing covers one physical USB drive and virtual drives in automated checks. It does not establish compatibility with every device, drive, or firmware.

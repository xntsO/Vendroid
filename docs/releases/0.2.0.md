# Vendroid 0.2.0

Vendroid 0.2.0 completes the GPT install lifecycle first shipped through V-Preview. It can install, detect, validate, update, and repair Ventoy GPT layouts while preserving the data partition, disk identity, partition boundaries, and user files during updates.

MBR remains the recommended default. Stable Vendroid directs drives larger than 2 TiB to the separately installable GitHub V-Preview until the large-capacity path passes physical testing.

## Release gate

Do not publish this release until the owner records passing results for:

- Phone and tablet testing with three different USB devices.
- UEFI boot and legacy BIOS boot where available.
- Install, reconnect detection, update, repair, and file-preservation checks.

The GitHub release contains the signed FOSS APK and its SHA-256 checksum. The workflow also retains the signed FOSS AAB for the existing Google Play application and signing identity.

After the owner approves GPT for stable, V-Preview remains separately installable and moves on to Release 3 testing.

Install and manage Ventoy on external USB drives from Android, without root.

Vendroid prepares a USB drive so you can keep multiple boot images on it and choose an image when booting a compatible computer. Use Android's file picker to manage supported boot image files.

Features
• Install Ventoy with an exFAT data partition.
• Detect, update, and repair supported existing Ventoy layouts.
• Use the bundled official Ventoy payload offline.
• Optionally download a compatible official Ventoy release through Vendroid's update mirror and verify its published checksum, without waiting for a new app release.
• Work directly with USB mass-storage devices after you grant USB permission.

You need an Android device with USB host support, a compatible USB drive, and an appropriate cable or adapter. Internal SD card slots are not supported. Hardware and boot-image compatibility varies.

Back up your USB drive before use. Installing Ventoy erases the selected drive. Keep it connected throughout an operation. Update and repair are intended to preserve ordinary files, but backups remain essential.

Stable releases currently support MBR drives up to 2 TiB. The Vendroid beta channel includes experimental GPT and larger-drive support. Beta replaces the stable Vendroid installation and may contain unfinished features.

Vendroid is open source and has no ads or account requirement. It uses work from Ventoy and EtchDroid and is not an official Ventoy project.
